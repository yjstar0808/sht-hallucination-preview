# SHT: A Self-Surprise Conformal Framework for LLM Hallucination Analysis

**Author**: Jie Yuan, Kean University (yuanjie@kean.edu)
**Status**: Preview repository — full implementation in a separate private repository.
**Submission target**: NLPCC 2026

## Overview

This repository contains the preview manuscript for *"SHT: A Self-Surprise Conformal Framework for LLM Hallucination Analysis"* — a three-layer framework combining:

- **Layer 1**: token-level e-process self-surprise monitoring
- **Layer 2**: trace-level per-category conformal calibration
- **Layer 3**: empirical bridge to claim-level hallucination labels

The framework is evaluated on a dataset of 667 atomic claims (560 factual + 107 hallucinated) generated by Qwen2.5-7B-Instruct under 25 prompts × 5 seeds, annotated by three independent LLM judges (DeepSeek V4 Pro, GLM-4.7, Claude Sonnet 4.6) with 3-annotator unanimity merge.

## Key contributions (preview)

**1. Theorem 13** (anytime-valid Type-I control): the wealth process $M_t = \prod_t(1 + \lambda s_t)$ on the centered Brier residual $s_t = \|q_t\|_2^2 - q_t(X_t)$ is a non-negative martingale under the sampling identity $H_0^{\text{stat}}: X_t \mid \mathcal{F}_{t-1} \sim q_t$. Ville's inequality gives $\mathbb{P}(\sup_t M_t \geq 1/\alpha) \leq \alpha$ exactly, distribution-free.

**2. Theorem 14** (trace-level per-category conformal): under within-category trace-level exchangeability, the per-trace summary score $\bar{A}_i^{(c)} = \max_k A_k$ satisfies $\mathbb{P}(\bar{A}_{\text{new}}^{(c)} > \bar{T}_{\alpha,c} \mid Y_{\text{new}}=\text{factual}, c) \leq \alpha + 1/(n_c^{\text{tr}}+1)$ on the false-alarm rate.

**3. Joint-characterization framing**: three-arm peeking-FAR comparison (Ville $1/\alpha$ vs conformal $c_A^*$ vs single-stop $c^*$) yields joint characterization of (anytime-valid status × calibration-target choice), rather than isolated attribution to anytime-validity.

**4. Channel U / Channel O taxonomy**: explicit decomposition of detectability — Channel U (uncertainty-driven) is in framework scope; Channel O (overconfident hallucination) is structurally outside the centered-Brier scoring rule's signal and is documented as future work.

**5. Honest empirical disclosures**: this dataset's hallucinated subset is Channel-O-leaning ($C_5$ = 28%, wider proxy $C_1 + C_5$ = 34.6%); per-category $n_c^{\text{tr}} \in \{13, 14, 17, 17, 17\}$ below the non-vacuous-quantile floor $\lceil 1/\alpha \rceil + 1 = 21$ at $\alpha = 0.05$. Empirical findings are reported with finite-sample CI caveats throughout.
